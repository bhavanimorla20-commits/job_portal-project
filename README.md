# 🚀 Job Portal Project

Job Portal application developed using React, FastAPI and PostgreSQL. This platform allows users to register, login, browse jobs and apply for jobs, while recruiters can manage companies and job postings.

---

## 📌 Project Overview

This Job Portal provides a complete recruitment platform for Job Seekers and Recruiters.

### 👤 User
- User Registration
- User Login
- Browse Jobs
- Apply for Jobs
- Profile Management

### 🏢 Recruiter
- Add Company
- Manage Companies
- Post Jobs
- View Applications

## ⚙️ Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
